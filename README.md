# 발표나침반

담임교사와 전담교사가 교실에서 바로 쓰는 **발표 방법 도감 + 진행 도우미** 웹앱입니다.
설치 없이 `index.html` 파일 하나로 동작합니다.

## 주요 기능

- **발표 방법 도감**: 34개 발표 방법을 분류, 형태(개인·짝·모둠·전체), 수업 단계, 발표 부담으로 찾아보기
- **추천받기**: 시간, 형태, 수업 단계, 반 분위기를 고르면 알맞은 방법 3개 추천
- **진행 모드(칠판 화면)**: 단계별 초시계 설정, 라운드 수 조절(월드카페, 둘 가고 둘 남기 등), 30초 전 알림, 자동 다음 단계, 종료음, 설정을 레시피로 저장
- **발표자 정하기 도구**: 공정 뽑기(생각하는 시간 포함), 텔레파시 가위바위보, 이웃을 사랑하십니까, 발표 화살표, 번개 발표 박자, 줄줄이·패스 명단, 릴레이 기록, 모둠 편성
- **우리 반 기록**: 여러 반 관리(전담교사용), 학생별 발표 횟수 기록

## 사용 방법

- 브라우저로 `index.html`을 열면 됩니다.
- GitHub Pages를 켜면 교실 PC나 전자칠판에서 주소로 바로 열 수 있습니다.

## 개인정보

학생 명단과 발표 기록은 **사용하는 브라우저(localStorage)에만 저장**되며 서버로 전송되지 않습니다.
처음 열었을 때 보이는 반과 학생 이름은 예시입니다.
