# 발표나침반

담임교사와 전담교사가 교실에서 바로 쓰는 **발표 방법 도감 + 진행 도우미** 웹앱입니다.
설치 없이 브라우저에서 열리고, 빌드 결과는 `index.html` 파일 하나라서 인터넷이 없는 교실 PC에서도 파일을 더블클릭해 쓸 수 있습니다.

## 주요 기능

- **발표 방법 도감** — 34가지 발표 방법을 분류, 형태(개인·짝·모둠·반 전체), 수업 단계, 발표 부담으로 찾아보기. 방법마다 단계, 시간, 선생님 팁, 참고 자료
- **추천받기** — 시간, 형태, 수업 단계, 반 분위기를 고르면 알맞은 방법 3가지와 추천 이유
- **진행 화면(칠판)** — 단계별 초시계, 라운드 반복(월드카페, 둘 가고 둘 남기 등), 30초 전 알림, 자동 다음 단계, 종료음, 시간 더하기·빼기, 키보드 조작(스페이스·←/→·Esc), 화면 꺼짐 방지, 전체 화면
- **수업 레시피** — 자주 쓰는 초시계 설정을 이름 붙여 저장하고 도감 맨 위에서 바로 진행
- **발표자 정하기 도구** — 공정 뽑기(적게 발표한 학생 우선, 이번 시간에 뽑힌 학생 제외, 생각하는 시간), 텔레파시 가위바위보, 이웃을 사랑하십니까, 발표 화살표, 번개 박자, 줄줄이·패스 명단, 릴레이 기록, 모둠 편성, 모둠 뽑기(발표할 모둠을 겹치지 않게 뽑고, 편성한 모둠이 있으면 모둠원도 보여 줌)
- **타이머** — 발표 진행과 따로 쓰는 기본 타이머(자주 쓰는 시간·직접 입력, 일시정지, 시간 더하기·빼기, 30초 전 알림, 끝나는 소리, 전체 화면)와 스톱워치. 다른 탭으로 옮겨도 계속 흐르고 메뉴에 남은 시간이 보임
- **우리 반** — 반 여러 개(전담교사용), 명단 붙여 넣기(나이스·엑셀 열 그대로), 학생별 발표 횟수, 직접 고치기, 백업 파일 내려받기·불러오기

## 개인정보

학생 명단과 발표 기록은 **사용하는 브라우저(localStorage)에만 저장**되며 어떤 서버로도 보내지 않습니다.
브라우저 기록을 지우면 함께 지워지므로, 우리 반 탭에서 **백업 파일**을 내려받아 두세요.
같은 컴퓨터에서 이전 프로토타입을 쓰던 경우, 그때의 명단과 레시피를 처음 열 때 자동으로 옮겨 옵니다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위·화면 테스트
npm run coverage   # 커버리지 (80% 미만이면 실패)
npm run build      # dist/index.html 한 파일로 빌드
npm run e2e        # 빌드 결과를 설치된 Chrome으로 열어 핵심 흐름 검사
```

`main` 브랜치에 올리면 GitHub Actions가 테스트, 빌드, 브라우저 검사를 거쳐 GitHub Pages에 배포합니다.
(저장소 Settings → Pages → Source를 **GitHub Actions**로 한 번 설정해야 합니다.)

### 구조

```
src/
  data/       발표 방법 34가지, 이름표, 출처
  domain/     화면과 무관한 규칙 (초시계·스톱워치 상태, 단계 펼치기, 공정 뽑기, 모둠 뽑기, 추천, 모둠, 명단 읽기)
  storage/    저장·검증·프로토타입 데이터 옮기기·백업
  state/      앱 상태(reducer)와 이번 시간 도구 상태
  ui/         화면 (도감, 추천, 진행 화면, 도구, 타이머, 우리 반)
  audio/      Web Audio로 합성하는 효과음
e2e/          실제 브라우저 흐름 검사
```
